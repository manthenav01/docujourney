# DocuJourney

DocuJourney is a Next.js application built with TypeScript and styled using Shadcn UI. This project aims to provide a seamless experience for users to navigate and manage documents efficiently.

## Features

- Dynamic document routing based on slugs.
- A dashboard for quick access to documents.
- Reusable UI components for consistent design.

## Getting Started

To get started with the DocuJourney project, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/docujourney.git
   cd docujourney
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```

## Project Structure

- `app/`: Contains the main application files including pages and layout.
- `components/`: Contains reusable UI components.
- `public/`: Static files such as images and icons.
- `styles/`: Global CSS styles.
- `.gitignore`: Specifies files to be ignored by Git.
- `next.config.js`: Configuration for Next.js.
- `tailwind.config.js`: Configuration for Tailwind CSS.
- `tsconfig.json`: TypeScript configuration.
- `package.json`: Project metadata and dependencies.
